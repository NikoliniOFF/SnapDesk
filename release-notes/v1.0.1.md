## 📸 SnapDesk для Windows 1.0.1

**Скачать:** `SnapDesk-1.0.1-win64.zip` ниже (или постоянная ссылка `SnapDesk-win64.zip`). Распакуйте и запустите `SnapDesk.exe` — значок появится у часов. Если SnapDesk уже установлен, он сам предложит обновиться.

### Что нового
- Новый логотип в едином стиле программ Nikolini: монитор с видоискателем и затвором камеры
- «Другие программы от Nikolini» во вкладке «О программе» теперь берутся из списка HubDesk: новые программы и их значки появляются без нового выпуска SnapDesk
- Проверка обновлений больше не ограничивается лимитом GitHub: если сервер отвечает «слишком много запросов», SnapDesk молча повторит проверку позже, без ошибок
- Актуальные значки всех программ Nikolini в списке и во встроенной копии (работает и без сети)

### Подробнее
- Список «Другие программы» загружается только при открытии вкладки «О программе» (не чаще раза в 6 часов), без фоновых таймеров. Выключится вместе с обновлениями («Новые версии: Не проверять»). Без сети показывается встроенный список.
- Версия обновления определяется без запросов к API GitHub; файлы и описание выпуска скачиваются напрямую, контрольная сумма SHA-256 проверяется как и раньше.
- Все остальное — как в 1.0.0: каждая функция включается отдельно, в простое процессор не тратится, без рекламы и без слежки.

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 (1903 или новее) или 11, 64-бит. Для записи нужна Windows с компонентами мультимедиа (в выпусках N — «Пакет дополнительных компонентов мультимедиа»).
